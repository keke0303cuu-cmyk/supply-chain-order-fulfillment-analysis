# Supply Chain Order Fulfillment Analysis

## Project Overview
An independent portfolio project analyzing historical Brazilian e-commerce order fulfillment performance using Python and pandas.

## Key Findings
- Analyzed 96,470 delivered orders with valid actual and estimated delivery dates.
- On-time or early delivery rate: 91.89%.
- Late delivery rate: 8.11%.
- Average delay among late orders: 9.55 days.
- Average customer review score: 4.29 for on-time or early orders and 2.57 for late orders.

## Tools

## Business Recommendations
- Monitor orders approaching their estimated delivery dates.
- Investigate monthly fluctuations in delivery performance.
- Track delivery KPIs alongside customer feedback.
- Investigate associations without assuming causation.
